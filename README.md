# rihen-houli

Personal portfolio of [Rihen Houli](https://github.com/rihenhouli) — Full Stack Engineer (Tunis).

Single-page Next.js 15 + Tailwind site listing six selected projects, professional experience, education, and contact info. CV data lives in [`src/lib/profile.ts`](src/lib/profile.ts); the project list in [`src/lib/projects.ts`](src/lib/projects.ts) — edit those to update the site.

## Run

```powershell
npm install
npm run dev
```

Opens at <http://localhost:3000>.

## Build

```powershell
npm run build
npm run start
```
